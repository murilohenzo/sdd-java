# caveman

Estilo telegráfico para respostas conversacionais quando solicitado explicitamente. Não é parte obrigatória do fluxo SDD e não deve ser ativado por um pedido genérico de concisão ou economia de contexto.

A skill preserva código, comandos, erros, especificações, contratos e evidências. O usuário pode mudar o estilo a qualquer momento. Não há garantia de redução percentual de tokens: o resultado depende do texto e do tokenizer.

Consulte [SKILL.md](SKILL.md) para os níveis de intensidade e as regras de clareza. Para o fluxo de desenvolvimento, consulte [o README do kit](../../../README.md).
